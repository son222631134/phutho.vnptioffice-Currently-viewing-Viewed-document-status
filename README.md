# Extension hiện trạng thái đang xem/đã xem trên nền tảng vbdh phutho.vnptioffice

1. Tải Tampermonkey Beta với link dưới đây

	[Tampermonkey BETA cho Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey-beta/fcmfnpggmnlmfebfghbfnillijihnkoh)

	[Tampermonkey BETA cho Chrome, Cốc cốc](https://chromewebstore.google.com/detail/tampermonkey-beta/gcalenpjmijncebpfijmoaglllgpjagf?hl=vi&pli=1)

3. Vào Quản lý tiện ích của trình duyệt, chọn Tampermonkey BETA, sau đó bật các mục sau:
	- Cho phép tập lệnh của người dùng (Allow user script)
	- Cho phép chế độ ẩn danh (Allow in Incognito)
	- Cho phép truy cập các URL của tệp (Allow access to file URLs)
4. Vẫn ở màn hình đó chọn Tùy chọn tiện ích (Extension options), sau đó bấm tab setting
	- General
		- Config mode: Chọn Advanced
	- Security
		- Store data in incognito mode: Chọn Permanent
5. Bấm [link này](https://github.com/son222631134/phutho.vnptioffice-Currently-viewing-Viewed-document-status/raw/refs/heads/main/script.user.js) để cài.
6. Truy cập [VBDH iOffice Phú Thọ](https://phutho.vnptioffice.vn/qlvbdh_pto/main) và sử dụng
